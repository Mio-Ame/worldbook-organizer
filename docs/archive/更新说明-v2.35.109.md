# **巨大更新**，更新说明：

1. 面板改成可拖动的浮窗，能拉边改大小，不再遮满屏幕；左边写世界书、右边继续聊天的双线操作终于成立了。手机端单独做了选书面板，点一下就是整屏选择。
2. 世界书现在能收藏也能置顶。收藏的书自动进入「已收藏」块，置顶的书固定在第一屏；「已开启的全局世界书」独立成块并常驻顶部，当前角色绑定的那本书紧跟其后，翻到哪个分组都不会找不到。
3. 新增全局方案快照：编辑框和全局框都能各自记住排除方案，分组胶囊的选择也会被记住，关掉再打开还是上次那格。
4. 编辑内容不用再来回跳页面：在插件里直接改世界书条目，也能直接把书绑给角色，改完即生效。
5. 对下拉框美化脚本做了完整适配。默认不去覆盖它的美化样式，想要统一观感可以在设置里让下拉框跟随酒馆主题。脚本环境下的搜索改由插件自绘结果列表，跨分组一把搜完，点一行就是选中或开关全局。
6. 修掉一批交互上的坑：点控件导致世界书抽屉被关、面板刚打开就自己关掉、页面被莫名滚动、搜索后列表空白、全部分组里多出空块。这些都是能稳定复现的，不是偶发。
7. 诊断重做：报告里能直接看到宿主版本、脚本与主题是否中途切换、每一阶段的列表状态与排列顺序、隐藏的行是被谁隐藏的。出问题时导出一次就能定位，并附上了反馈入口。

### 相对上一次 main（v2.35.16）到底变了什么

- **形态**：全屏面板 → 可拖动可缩放的浮窗；移动端补齐专用选书面板。
- **组织**：只有分组 → 分组 + 收藏 + 置顶 + 全局块 + 当前角色书置顶，五套位置各司其职。
- **下拉框**：只适配原生 → 原生与美化脚本双路径，脚本环境搜索不再受宿主过滤牵制。
- **能力**：只看不改 → 面板内直接编辑条目、绑定角色、保存全局方案。
- **可维护性**：出问题靠肉眼 → 结构化诊断（阶段快照、顺序指纹、隐藏原因、脚本/主题切换记录）。

## 8. ESM 副作用顺序（拆分核对表）

拆分时必须保持的顶层副作用顺序（`index.js` 的实际执行链）：

1. `index.js` 顶层：import 求值顺序 →
   `src/core.js`（无副作用）→ `src/host.js`（仅定义）→ `src/native-filter.js`（**模块顶层只定义**：常量与本文件状态初始化）→
   `src/panel.js` → `entry-groups/lifecycle.js` → `feature-gate.js` → `content-scroll.js` → `panel-manager.js` → `import-organizer.js`
2. `index.js` 顶层常量 `STYLE_ASSET_VERSION` 赋值。
3. `boot()`（顶层立即调用）：注册 APP_READY once / jQuery ready / DOMContentLoaded 三路延迟启动；**不建 DOM**。
4. `init()`（异步，首次 `requestIdleCallback`/250ms/400ms 后）内按序：
   `setNativeScrollEnabled(true)` → `waitForTauriReadyIfPresent()` → 设置迁移 → `ensureWorldInfoModule()` →
   `ensurePowerUserModule()` → `syncFallbackSettingsData(false)` → `bindPanelCallbacks(...)` →
   移除旧抽屉挂载 → `recomputeAndRender({save:false})`（内部 `applyAllNativeWorldFilters` → `renderEmbeddedPanel`）→
   `document.addEventListener('change', captureWorldbookImport, true)` → `startNativeObservers(...)`（建立 MutationObserver）→
   jQuery `change.wbo` 委托 → 宿主事件订阅（顺序固定）→ 等待角色加载的兜底计时器 →
   `window` 的两个自定义事件（`wbo:open-panel`、`weg:entries-toggled` / `weg:entry-saved`）→
   `registerSlashCommands` → `ensureFreshStylesheet()`（**样式注入点**）→ `configureEntryGroupingFeatureGate(...).sync()`
5. `onDisable()`：逆序拆解，先断事件与计时器，再 `teardownNativeFilters()` / `teardownPanels()`，最后移除 `assetRoot` 下的样式 `link`。

拆分约束（写进每个阶段的验收）：
- 被拆出的子模块**只允许有声明，不允许有顶层副作用**（无 DOM 操作、无 `setTimeout`、无 `addEventListener` 调用）。
- `native-filter.js` 仍必须是「第一个被引入并完成定义的模块」，子模块只能通过 `import` 从它取值，避免改变观察器/单例建立时机。
- 样式注入顺序由 `src/style-manifest.js` 的数组顺序唯一决定，`<link>` 按数组顺序 append，**不允许**用 `@import`（`@import` 会改变首屏时序与缓存键）。

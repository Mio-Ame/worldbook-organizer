# 世界书分组管理 (Worldbook Organizer)

适用于 **SillyTavern**（1.14–1.19+）与 **TauriTavern**（桌面端 & 移动端 / iOS）的纯前端世界书分组、角色书自动收纳与智能整理扩展。

## 核心亮点

### 1. 自动识别角色卡世界书与按分组过滤
- 自动识别所有角色卡绑定的**主世界书**、**附加世界书**及可选的**内嵌同名世界书**，统一归入「角色世界书」分组。
- **分别隐藏不需要的分组**：支持分别为「全局激活」和「编辑世界书」下拉框设置要隐藏的分组（默认隐藏角色世界书，也可自选任意分组如小剧场、归档等）；在分组标题眼睛图标、世界书顶部工具栏或 `/wbo` 可随时一键切换。
- **当前角色书自动置顶**：进入某个角色聊天时，编辑世界书下拉框会自动把该角色绑定的世界书置顶显示，即使当前隐藏了角色世界书也能直接打开编辑。
- **按角色名清晰展示**：自动将角色世界书显示为绑定的角色名（可选保留小字原标题、仅显示角色名或保留原标题），支持按角色名与原文件名联合搜索。
- **安全保护**：已全局激活或当前正在编辑的世界书不会被隐藏，避免误关或打断编辑。

### 2. 自定义分组管理、跨书搜条目与多弹窗适配
- 从聊天栏魔棒菜单即可打开独立分组管理面板：支持自定义分组、配色、置顶分组栏、折叠与吸顶标题、拖拽排序、批量勾选移组/删除、一键预览条目与全局激活开关。
- **统一搜索 & 跨世界书搜条目**：搜索框支持按需勾选范围（世界书名 / 角色名 / 条目内容，可选空格分隔多词同时匹配），自带最近搜索记录；命中条目支持一键打开世界书并高亮定位到对应条目，世界书面板顶部也提供快捷搜索入口。
- **原生下拉与多弹窗适配**（均可在设置中按标签页自由开关，顶部快捷按钮亦可按需隐藏）：
  - 世界书编辑下拉框：桌面端与移动端均支持分组折叠、搜索与当前角色书置顶；
  - 角色主/附世界书弹窗：主书置顶「当前角色」、附书置顶「已选附加书」并采用右侧防误触按钮切换；
  - User 人设世界书、聊天世界书、条目移动/复制目标弹窗均支持分组与搜索。

### 3. 免 AI 整理 & AI 整理（默认不改动原文件）
- **免 AI 整理（默认首页）**：零 Token 消耗、本地即时归类。内置 12 个常用酒馆分类标签（默认勾选 `User 人设`、`文风`、`NSFW`，其余一键勾选），支持按书名前缀自动建组、自定义关键词规则与清理标题后缀。
- **AI 整理**：支持使用酒馆当前 API、自定义多组 OpenAI 兼容通道，或免 API 的外部 AI 复制粘贴 JSON 模式；内置疑似敏感词自动避坑、可视化预览勾选与微调、不满意选组重排。
- AI 选书可切换「正常世界书」与「疑似敏感世界书」。勾选疑似敏感书后，可以直接归入指定分组和撤回。
- **零破坏 + 多步撤销**：默认只写入插件虚拟显示名与分组，不改底层世界书文件名，角色/人设/聊天/脚本绑定保持不变；如需同步重命名真实文件，也提供可选的「真实改名并同步绑定」模式。支持最多 8 步历史快照与一键还原最初状态。

### 4. 角色绑定扫描与双书对比
- 在插件主面板点世界书旁的「绑定」。手机或窄窗可点「··· → 绑定到角色」，也可以展开世界书后点「绑定世界书到角色」。核对头像后选择「设为主世界书」或「添加为附加世界书」，替换主世界书前会显示原书名。
- 一键排查未绑书角色、缺失文件、共用书、多书角色、卡内同名书与失效附加绑定，支持跳转角色卡、直接解绑、按需预览条目及任意两本世界书的条目差异对比。
- 在世界书行点小地球，核对角色头像后可设为主世界书或添加为附加世界书。替换主书前会显示原书。

### 导入归类与条目分组

- 在「设置 → 识别与适配 → 导入归类」设置标题规则。原生文件导入时，规则只检查书名并跳过角色书和已分组书。第一次发现疑似敏感书时，可选择已有分组、当场新建或跳过。
- 世界书行的「条目分组」打开内置面板。已有条目分组和存档路线可直接使用。若旧独立版仍启用，关闭它并刷新后即可改用内置面板。

### 5. 轻量低负载 & 多端颜值适配
- 无轮询、无后台扫盘，仅在打开面板或数据变化时按需刷新；支持角色卡懒加载模式，自带配置导入/导出备份。
- 内置 5 套明暗自适应配色（默认「素雅纸墨」），弹窗外的下拉列表默认跟随当前酒馆主题；电脑端窗口支持拖动，手机端自动全屏适配。

## 安装方式

**推荐（SillyTavern / TauriTavern 扩展管理器一键安装）**：

1. 打开酒馆 → 顶部「扩展」面板 → 点击「安装扩展」
2. 填入仓库地址：
   ```text
   https://github.com/Mio-Ame/worldbook-organizer
   ```
3. 安装完成后刷新页面即可使用。

**手动安装**：将本仓库放入 `SillyTavern/data/default-user/extensions/worldbook-organizer`（或 TauriTavern 对应 `extensions/` 目录），重启/刷新即可。

## 快捷命令

- `/wbo` 或 `/wbo toggle`：一键切换角色世界书显隐
- `/wbo show` / `/wbo hide`：显示或隐藏角色世界书
- `/wbo rescan`：手动重新扫描角色绑定
- `/weg`：打开条目分组。也可以附上分组名或世界书名。
